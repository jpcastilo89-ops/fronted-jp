# ZETA · Premium Wear (prototipo web)

Web estática de ZETA (Carora, Lara). Las ventas se cierran por WhatsApp.

- Todos los datos de contacto y del producto están en `config.js`.
- Sitio estático: no necesita compilar. Render publica la carpeta raíz (`./`).
- Las páginas se generan desde las plantillas del proyecto con `construir.py`.
